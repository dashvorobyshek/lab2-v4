## Описание реализации (Доказательство выполнения)

### Средняя сложность №4
Создан файл `task4.py`. 
Реализован алгоритм Евклида для вычисления наибольшего общего делителя (НОД). Добавлен бесконечный цикл `while True` и блок `try-except ValueError` для защиты программы от ввода букв или некорректных символов. Использована функция `abs()` для корректной работы с отрицательными числами.

### Средняя сложность №6
Создан файл `task6.py`. 
Написан консольный калькулятор, поддерживающий базовые арифметические операции (`+`, `-`, `*`, `/`). В коде реализована защита от деления на ноль, а также проверка правильности ввода оператора и числовых значений с помощью конструкции `try-except`.

### Средняя сложность №10
Создан файл `task10.py`. 
Написана функция `generate_squares_dict(n)`. Для формирования результата применен генератор словарей (dict comprehension) `i: i**2`. Добавлена проверка, чтобы пользователь мог ввести только целое положительное число.

## Повышенная сложность №5
Создан файл `task5pov.py`. 
Импортирован встроенный модуль `random` для генерации случайного числа от 1 до 100. Реализован игровой цикл, который дает пользователю подсказки («больше»/«меньше») и подсчитывает количество затраченных попыток до правильного ответа.

## Повышенная сложность №9
Создан файл `task9pov.py`. 
Реализована рекурсивная функция суммы чисел от 1 до N. Базовый случай выхода из рекурсии: `n == 1`. Для защиты программы от сбоев при вводе слишком больших чисел добавлена обработка системного исключения `RecursionError` - программа не вылетает с ошибкой, а просит ввести число меньше системного лимита.
